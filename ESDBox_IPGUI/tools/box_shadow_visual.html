Box Shadow 渲染实验

IPGUI · ipgui_draw_box_shadow

圆角缺口阴影从控件自己的圆角里透出来

阴影画在卡片背后。卡片圆角弧线以外的角部是透明的，而阴影恰好覆盖到这里，于是透出一块带弧边的灰三角。右上角是 3× 放大。

圆角16
模糊12
扩散12
不透明度220
按 CSS 裁掉边框盒

CSS 规则：外阴影只画在 border-box 之外。圆角缺口属于 border-box，必须挖空。

绘制区域控件矩形不够大，阴影被齐边切掉

框架交给控件的是它自己的矩形。阴影要画到盒子外面，矩形不够大就会被裁，看起来像“外层没有递减”。蓝色虚线是控件的绘制区域。

绘制区域外扩8
模糊24
显示控件矩形

约束：控件尺寸要比可见盒子每边多 pad + max(offset, 0)，pad ≈ 0.75 × blur。

管线与 C 实现一致：圆角覆盖率 mask → 3 趟居中均值模糊 → mask × opacity 混合。
